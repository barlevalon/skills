# release-prep

Evidence-backed release preparation for software repos.

Use this skill when preparing releases, choosing SemVer bumps, drafting changelogs or release notes, validating release readiness, replacing commit-driven release automation, or creating project-local release policy.

## Use

Read the entry point directly or copy this complete folder, including its license, into a skill directory supported by the chosen harness. This repository does not provide an installer or npm package.

Publication and deployment actions described by the skill still require explicit approval.
